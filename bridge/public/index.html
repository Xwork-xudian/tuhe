接入途合

在途合「平台连接」中把目标平台切换为 Webhook，填入下面的地址与令牌。

/webhook
  1. 抓一次请求：在浏览器开发者工具 Network 中完成一次「添加收藏」，复制请求 URL、Request Headers 和 Payload。
  2. 复制 Cookie：从请求头或 Application → Cookies 复制完整 Cookie。
  3. 配置并预览：先保持预览模式，点「测试」检查渲染结果。
  4. 小批量试跑：关闭预览后先在途合同步 1 个地点，确认平台端出现。
  5. 正式同步：逐步扩大范围；保持低频，必要时调大请求间隔。
仅用于你自己的账号。平台接口可能随时变化，自动化操作存在被风控或封号的风险；本项目不会绕过验证码或二次验证。

安全说明

Cookie 加密存储，接口不会回显明文；日志只保留请求结果，不记录 Cookie。建议只在局域网运行本服务，并设置管理令牌与 Webhook 令牌。
